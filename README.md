# 基于 FreeRTOS 的微波炉控制系统

STM32F103C8T6 + FreeRTOS V9:从裸机整机到 RTOS 三任务架构的完整迁移,含串口 IAP 固件升级与 Tickless 低功耗。业务代码全部独立实现,25 天四阶段开发。

## 功能

- 按键长短按:开关门 / 加热时长(20~200s)/ 三挡功率切换
- 0.05Hz 慢 PWM 三挡平均功率驱动继电器(避免机械触点高频开关)
- DHT11 温湿度监测,加热中超温自动开门断电声光报警
- LCD(SPI) 界面显示(时间/功率/门状态/温湿度)
- 串口 IAP:DMA 定长收固件 → 复位向量校验 → 写片内 Flash 备用分区 → RTOS 环境跳转
- Tickless 低功耗:空闲窗口拉长至 100ms,WFI 睡眠实测生效

## 任务架构

| 任务 | 优先级 | 职责 | 同步方式 |
|---|---|---|---|
| iap | 6 | 固件接收/擦写/跳转 | 二值信号量(USART1 DMA TC 中断 Give) |
| cooking | 5 | 秒拍倒计时/完成流程 | 二值信号量(TIM4 1s 中断 Give) |
| key | 4 | 按键事件消费/开关门/点火 | 位掩码标志轮询(TIM3 10ms 扫描置位) |
| dht | 2 | 温湿度 2s 周期采集 | vTaskDelay |

中断原则:ISR 只递信号量,业务逻辑全部在任务中(打铃与干活分离)。

## IAP 升级演示

1. 烧录本工程(B 区,含 IAP)
2. 串口助手 115200 以"发送文件"方式发送 APP 固件 bin
3. 自动完成:DMA 收满 → 复位向量校验 → 擦写 A 区 → 跳转
4. 按复位键回到微波炉主固件,可无限次重演
